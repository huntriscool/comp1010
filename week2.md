# Loops and Arrays

- Lets say you have an array with 10 numbers and you want to know how many of those are even. you would need a loop to go through every item in the array and use a condition to check if the number is even

```
int[] array1 = {1, 2, 3, 4, 7, 10, 99, 88, 0, 10}; //creates an array with the given 10 values
int count = 0; //creates an int variable that will count
for(int i = 0; i < array1.length; i++){
     if(array1[i] % 2 == 0){
          count++;
     }
}
return count;
```
